# discourse-tags-auto-no-bump

带有指定标签的话题，新回复将不顶帖。

## 标签页按最后回复时间排序

这些话题不再顶帖，所以在这些标签自己的页面里，话题改按**最后回复时间**排序，“活动”一栏也显示最后回复时间，否则有新回复的话题会一直沉在下面。这些页面包括 `/tag/标签`、分类下的标签页 `/tags/c/…/标签`，以及含有这些标签的标签交集页。

其他页面照常按顶帖时间排序和显示，例如最新、分类，以及其他标签的页面（即使话题同时带有这些标签）。在这些标签的页面里，下面这些也保持原样：

- 手动选择的其他排序，例如按回复数、浏览量或创建时间排序，以及分类设置的默认排序；
- 新、未读、排行、热门列表各自的排序。

顶帖时间和最后回复时间的区别：

- **顶帖时间**：core 在有新回复、编辑 wiki 首帖、移入帖子等情况下更新。对于这些话题，本插件让这些操作都不再更新它。
- **最后回复时间**：话题里最后一帖的发帖时间。
  - 新回复会更新它，包括这些话题里不顶帖的回复；
  - 移入的帖子成为最后一帖时会更新它；
  - 关闭、置顶等状态变更在帖子流里留下的提示也会更新它；
  - 悄悄话和静默发出的帖子不会更新它；
  - 编辑帖子不会改变它；
  - 删除最后一帖后，它回到剩下的最后一帖的时间。

## 安装

按 Discourse 插件的通常方式安装：https://meta.discourse.org/t/install-a-plugin/19157

## 设置

- `tags_auto_no_bump_enabled`：总开关，默认关闭。关闭后所有话题照常顶帖，标签页也照常按顶帖时间排序。
- `tags_auto_no_bump_tags`：标签列表，默认为空。
